# Praktik ISR - Next.js (App Router)

Starter project untuk jobsheet **Incremental Static Regeneration (ISR)**.

## Mulai
```bash
git clone <URL-REPO-INI>
cd isr-jobsheet
npm install
cp .env.local.example .env.local     # Windows CMD: copy .env.local.example .env.local
```
Lalu buka **JOBSHEET.md** dan ikuti langkahnya dari Langkah 1.

## Penting
ISR hanya terlihat di mode production:
```bash
npm run build
npm start
```
**Jangan** memakai `npm run dev` untuk praktik ini.
